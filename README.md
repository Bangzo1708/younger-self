Entrants write one line, in English, that they would send back to their younger self if a single line were all they got: no explanation, no context, no second sentence. Each entry is that line alone, up to 200 characters. A judge model compares entries two at a time against a brief published with the bounty, rewarding a line only this person's older self could write, one that lands in a breath and stays after a single reading. The best ranked line takes the whole reward.

## Run it

```sh
python3 main.py
```
